## Capstone 3 Project:  Customer segmentation and real-time purchase intent modeling for e-commerce optimization

### Executive Summary

This project builds an end-to-end Customer Analytics System using transactional and clickstream data to improve e-commerce decision-making and conversion performance.
A DBSCAN-based customer segmentation model identifies five distinct behavioral segments, enabling targeted personalization, onboarding, and frequency-driven marketing strategies.
A session-level purchase prediction model uses real-time behavioral signals to detect purchase intent during active browsing sessions.
The model is optimized through threshold tuning to support early, in-session intervention, rather than post-purchase analysis.
Together, the models demonstrate how behavioral data can power real-time intent monitoring, smarter marketing activation, and measurable revenue lift.
